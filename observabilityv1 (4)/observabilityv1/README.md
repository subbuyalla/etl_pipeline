# Vithi Observability v1 Enterprise Pack

This directory contains the complete, production-ready **Vithi Observability Consulting & Business Development Pack**. All documents are organized by customer engagement lifecycle and audience.

> **Cloud Coverage Note:** Documents in Folders 01-04 are **AWS-specific** (prefixed Vithi_AWS_). For Azure, GCP, Hybrid, or vendor-neutral engagements, use the general appendices in Folder 05.

---

## Folder Structure & Document Map

### 01_Sales_and_Customer_Onboarding/
Purpose: Top-of-funnel customer discovery, commercial qualification, offer positioning, and Day-1 kickoff boundary governance. AWS-specific edition.

- Vithi_AWS_Observability_Readiness_OnePager.docx
  Executive summary of Vithi AWS SRE offering, canonical O0-O12 capability stack, moderated targets, and engagement tracks.

- Vithi_AWS_Observability_BD_PreDiscovery_Intake_Form.docx
  Lightweight 2-page discovery sheet for the initial 30-minute introductory meeting capturing the 10 core customer signals (AWS-focused).

- Vithi_AWS_Observability_Engagement_Models_and_Scoping_Guide.docx
  Commercial SOW scoping asset defining the 2 standard engagement variants: Rapid 2-Week Diagnostic vs. Full 4-Week AWS Enterprise Assessment.

- Vithi_AWS_Observability_Assessment_Scope_and_Exclusions_Charter.docx
  Day-1 kickoff agreement locking down in-scope Tier-1 services, AWS production account IDs, 100% read-only access, and explicit contractual exclusions.

- Vithi_AWS_Rapid_Observability_Diagnostic_2Week.docx
  Standalone BD offer brief for Track A - 2-Week engagement (AWS). All 7 sections: Scope O0-O6, Participants, Evidence EV01-EV06, Activities, Outputs, Exclusions, Effort (~3.5 Vithi days / ~6-8 customer hours).

- Vithi_AWS_Full_Observability_Assessment_4Week.docx
  Standalone BD offer brief for Track B - 4-Week engagement (AWS). All 7 sections: Scope O0-O12, Participants, Evidence EV01-EV13, Activities, Outputs incl. Illustrative Value Blueprint, Exclusions, Effort (~9-10 Vithi days / ~20-25 customer hours).

## Assessment Engagement Variants Quick Reference

| Parameter              | Variant A: Rapid Diagnostic (2-Week)          | Variant B: Full Assessment (4-Week)                  |
|------------------------|-----------------------------------------------|------------------------------------------------------|
| Duration               | 2 Weeks (10 Business Days)                    | 4 Weeks (20 Business Days)                           |
| Estate Scope           | 1-3 critical Tier-1 services                  | Full enterprise estate + Data Platform + AI          |
| Evaluated Dimensions   | Core O0-O6                                    | Complete Canonical O0-O12                            |
| Evidence Required      | Core EV01-EV06                                | Complete EV01-EV13                                   |
| Customer Time          | ~6-8 hours across 2 weeks                     | ~20-25 hours across 4 weeks                          |
| Primary Deliverables   | Heatmap, Top 5 Gaps, Value Summary, 90-Day Roadmap | Full Heatmap, Value Blueprint, Tool Rationalization, Exec Deck, 12-Month Roadmap |
| AWS document set       | Vithi_AWS_* (Folders 01-04)                   | Vithi_AWS_* (Folders 01-04)                          |
| Non-AWS document set   | Vithi_General_* (Folder 05)                   | Vithi_General_* (Folder 05)                          |
